Request Data Flow

User selects filter
FilterBar dropdown updates useFilters() singleton ref — shared reactively across all views.
Watch triggers reload
Each view watches [selectedPeriod, selectedLocation, selectedCategory, selectedStatus] and calls loadData().
api.js builds request
Axios appends only non-'all' values as query params: ?month=2025-01&warehouse=London.
FastAPI filters data
apply_filters() sequences warehouse → category → status. filter_by_month() handles both exact months and quarters (Q1–Q4).
Pydantic validates
Response serialized through typed model (e.g. List[Order]) before JSON is returned.
Refs and computed update
Response assigned to raw ref (allOrders). Computed properties (charts, KPIs, tables) recalculate automatically.

API Endpoints

Method Path Query Params Description
GET /api/inventory warehouse, category Full inventory list with optional filters
GET /api/inventory/{id} — Single inventory item by ID (404 if not found)
GET /api/orders warehouse, category, status, month Orders list; month accepts YYYY-MM or Q1-YYYY
GET /api/orders/{id} — Single order by ID
GET /api/dashboard/summary warehouse, category, status, month KPI aggregate: inventory value, low-stock count, pending orders, backlog total
GET /api/demand — All demand forecasts (no filters)
GET /api/backlog — Backlog items with computed has_purchase_order flag
GET /api/spending/summary — Total costs by category (procurement, operational, labor, overhead)
GET /api/spending/monthly — Month-by-month cost breakdown (12 months)
GET /api/spending/categories — Spending grouped by category
GET /api/spending/transactions — Recent financial transactions
GET /api/reports/quarterly — Q1–Q4 2025: orders, revenue, fulfillment rate, avg order value
GET /api/reports/monthly-trends — Monthly order count, revenue, and delivery counts

Key Patterns

State Management
Singleton Composable
useFilters() stores refs at module scope (outside setup()), so every component that calls it shares the exact same reactive state — no Pinia/Vuex required.
Filtering
Server-side filters, client-side search
Warehouse / category / status / month filters are sent as query params to the API. Inventory free-text search is a client-side computed() over the already-loaded list.
Reactivity
Raw refs + derived computeds
API responses land in raw refs (allOrders, inventoryItems). All chart data, KPIs, and table rows are derived computed properties — never stored separately.
UI
Teleport-based modals
All overlays use <Teleport to="body"> to escape the component tree and avoid z-index stacking issues. Transitions use Vue's <Transition> wrapper.
i18n
Locale-driven currency
Switching to Japanese (ja) automatically switches currency to JPY. Currency is not independently selectable — locale and currency are always in sync via useI18n().
Backend
Computed flag on backlog
The /api/backlog endpoint joins backlog_items with purchase_orders at request time to add a has_purchase_order flag — no mutation of source data.
